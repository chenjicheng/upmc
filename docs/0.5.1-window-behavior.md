# PCL launch and updater window lifecycle

Launching PCL successfully leaves the updater running. New and legacy settings
default to keeping its window visible. The settings switch `启动游戏后隐藏窗口`
persists `hide_after_launch` in `updater/settings.json`; it uses the existing
optimistic, serialized switch queue and rolls back a failed save. Settings remain
disabled during an update or launch, consistent with the other switches.

When enabled, a successful launch creates the Windows tray icon before hiding
the window. A left-button release on the icon shows, unminimizes, and focuses the
updater. The Slint event loop stays alive while hidden. Both the custom close
button and native window close quit when idle; busy-close protection remains.
PCL launch failures never hide the window. Tray creation/hide errors and restore
errors are retained in the existing shared error-details surface.
