# Review adjudication for 0.5.0

The primary verified each automated finding from PR #27 against the 0.4.8 backend and the new UI adapter before accepting it.

| Finding | Decision and evidence |
| --- | --- |
| Show proxy progress in footer | Rejected as a requirement mismatch. The user explicitly requested immediate optimistic switch state and no connecting/stopping intermediate labels. The footer shows intent rather than claiming a verified live connection. Documentation now makes this intentional behavior explicit. |
| UDP save reloads stale channel | Accepted. A saved UDP value must not override a CLI-selected channel. The acknowledged active request updates only its own cached setting; a second file read is unnecessary. The acknowledgement test failed before the fix and passes afterward. |
| Offline recheck clears live proxy | Accepted. `run_game_update` returns Offline before any proxy start/stop effect. The UI now retains known proxy state. The focused state test reproduced the false-off result before the fix. |
| Channel save leaves stale window title | Accepted. Applying the acknowledged channel now also refreshes its title. The native-view test asserts the title matches the selected channel. |
| Stop worker creation failure reports off | Accepted. No stop operation ran, so the prior proxy state is restored by `fail_before_start`. A focused test failed before the fix and passes afterward. The enabled failure marker links to the shared error window. |
| Both workflows build branch pushes | Accepted. Historical 0.4.8 workflow no longer receives branch pushes; its original tag and manual entrypoints remain. The current Slint workflow owns branch validation. The trigger regression failed before removal and passes afterward. |

Additional user-requested corrections have behavioral coverage: immediate repeated clicks, pending-choice coalescing, stale completion handling, retaining a proxy reapply after a settings change, persistence-failure rollback, delayed busy hints, fixed error-marker geometry, and collecting complete failures in one window. No production proxy or update implementation was replaced to satisfy UI tests.
