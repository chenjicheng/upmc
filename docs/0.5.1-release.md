# UPMC 0.5.1

Includes the Slint and UDP-on migration documented in [0.5.0-slint-release.md](0.5.0-slint-release.md). The v0.5.0 tag is retained, but its publication was cancelled before a Release or Pages promotion. The exact publisher and tag gate now target v0.5.1; frozen 0.4.8 entrypoints remain unchanged.

Two late review findings were reproduced and fixed before this publication:

- An already-closed Discord stays closed when migrating proxy.txt. Configuration changes restart only a previously running Discord, using a checked process query. An unchanged configuration does not query/restart it.
- UDP and channel jobs retain separate error identities. A queued save of another setting does not hide the preceding failure; retrying the same setting clears its marker. Detailed records remain in the shared error window.

Primary RED/GREEN evidence is in the corresponding behavioral tests. Release acceptance requires CI and public artifact/feed verification.
