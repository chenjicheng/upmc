# UPMC 0.5.5

Fix misleading idle feedback while a proxy operation is still running. After
the existing 300 ms grace period, the primary action visibly waits, actual
proxy progress is shown, and proxy text distinguishes work in progress from
completion. Close feedback identifies the active task and clears when it ends.
Queued switch intent and task serialization are preserved. This release does
not shorten network retries or interrupt active installation/cleanup.

The manifest selects version 0.5.5 and publication predecessor 0.5.4. The
predecessor is a server-side publication consistency check, not a minimum
client version: clients already reading the bridge feed, including 0.5.3, may
upgrade directly. Frozen legacy entrypoints and historical markers remain
unchanged. Publication requires the exact main commit's canonical green
validation, build and CodeQL runs, followed by the official tag build.

The GUI change was tested before implementation: two new regression tests
failed on missing long-job feedback, then 28 GUI/state/queue tests passed.
Independent review approved the exact GUI snapshot. Three desktop tests were
not run in that focused suite. Strict local Clippy was blocked by existing
`unnecessary_sort_by` and `ptr_arg` findings in the unchanged proxy library;
this is not a claim of a clean Clippy run.
